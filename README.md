#  Pomodoro Fofo <3

Aplicativo de estudos desenvolvido em Java Swing.

## Funcionalidades:
- Timer Pomodoro (25 min)
- Pausa curta
- Pausa longa
- Contador de pomodoros
- Interface rosa fofa

## Tecnologias:
- Java
- Swing
- NetBeans

## Objetivo:
Projeto para praticar lógica de programação e interface gráfica.
